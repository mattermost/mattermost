A Mattermost plugin consists of several components:

- [Server](./server/index.md): subprocesses invoked by the Mattermost Server that communicate using RPC
- [Webapp](./webapp/index.md): extensions/modifications to the Mattermost web and desktop apps
- [Mobile](./mobile/index.md): mobile device support
