Evaluate Mattermost without a full production deployment. Use a hosted sandbox for an instant look at the product, or spin up a short-lived instance with Docker or Azure.

## 1-hour cloud preview

The fastest path: submit a short form on mattermost.com, then Mattermost provisions a live sandbox for about one hour.

<TryMattermostCTA />

<Tip>
After you submit the form, you are redirected to the Customer Portal, which creates the preview workspace and signs you in. No local install is required.
</Tip>

More detail: [1-hour cloud preview](/for-evaluators/one-hour-cloud-preview).
