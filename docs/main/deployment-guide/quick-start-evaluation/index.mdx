Use these options when you want to explore Mattermost before planning a production deployment. They are for evaluation only — not production use.

## In this section

- [1-hour cloud preview](/deployment-guide/quick-start-evaluation/one-hour-cloud-preview) — hosted sandbox with no local install; about one hour of access after sign-up.
- [Docker or Azure Marketplace](/deployment-guide/quick-start-evaluation/docker-and-azure) — run a preview container locally, or deploy an evaluation VM from Azure Marketplace.

Want a guided walkthrough instead? [Book a live demo](https://mattermost.com/request-demo/) or [talk to a Mattermost expert](https://mattermost.com/contact-sales/). Or browse the [Demo Library](https://mattermost.com/resources/learn/demo-library/) for self-guided product demos.
