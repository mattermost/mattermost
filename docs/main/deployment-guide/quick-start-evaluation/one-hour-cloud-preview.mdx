Use the hosted **1-hour cloud preview** when you want to explore Mattermost in a live environment without installing anything.

## How it works

1. Open the sign-up form (button below).
2. Enter your business details and choose a use case.
3. After you submit, a preview workspace is created and you are signed in for about one hour.

<TryMattermostCTA />

## When to use something else

- Need a longer trial you control? Use [Docker or Azure Marketplace](/deployment-guide/quick-start-evaluation/docker-and-azure).
- Want a guided walkthrough? [Book a live demo](https://mattermost.com/request-demo/) or [talk to a Mattermost expert](https://mattermost.com/contact-sales/).

<Important>
The cloud preview is for evaluation only. It is not a production workspace, and data is not retained after the preview expires.
</Important>
