---
title: "Desktop app policies"
---
<PlanAvailability slug="all-commercial" />

Policies let you set servers for your users, and control server management, update checks, and embedded media permissions. Users can't change policy values through the app's interface. To set them, see [Configure policies on Windows](/deployment-guide/desktop/windows-desktop-install#configure-policies) or [Configure policies on macOS](/deployment-guide/desktop/macos-desktop-install#configure-policies).

<Important>

On Windows, user-level registry policies take precedence over machine-level policies. A user with write access to their `HKEY_CURRENT_USER\SOFTWARE\Policies\Mattermost` registry key can override machine-level `EnableServerManagement` and `EnableAutoUpdater` restrictions. If you need to enforce these policies reliably, restrict user access to their policy registry keys using Group Policy or other access controls.

</Important>

| Policy | What it does | Available from |
|---|---|---|
| `DefaultServerList` | Adds one or more permanent servers that users can't edit or remove. These servers are trusted, so users aren't asked to grant them permissions such as notifications, camera, and microphone, including for content embedded in them. This means these servers don't need a `TrustedEmbeddedMediaOrigins` entry. The operating system's own permissions still apply. | Windows v4.3, macOS v6.2 |
| `EnableServerManagement` | When disabled, users can't add, edit, or remove servers, so set at least one server with `DefaultServerList`. | Windows v4.3, macOS v6.2 |
| `EnableAutoUpdater` | When disabled, the app doesn't check for updates or show update notifications. | Windows v5.1, macOS v6.2 |
| `TrustedEmbeddedMediaOrigins` | Lets embedded content from another origin, such as a meeting service embedded in Mattermost, use the camera and microphone permission granted to a Mattermost server. It isn't needed for servers set with `DefaultServerList`. | v6.3 |

The app reads policies when it starts, so changes take effect after Mattermost restarts.
