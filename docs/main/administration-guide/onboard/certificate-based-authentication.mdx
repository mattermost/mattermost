unlisted: true
---

<Important>

**Experimental certificate-based authentication was removed in Mattermost v11.0.** Its remaining configuration setting was removed in Mattermost v12.0.

</Important>

For client certificate validation at the reverse proxy, see [SSL client certificate setup](/administration-guide/onboard/ssl-client-certificate). This validates connections to the proxy and does not replace signing in to Mattermost.
