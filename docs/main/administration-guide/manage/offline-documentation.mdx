---
title: "Offline Documentation"
description: Read the product documentation bundled with Mattermost releases without internet access.
---

<EditionAvailability tiers="professional,enterprise,enterprise-advanced" />
<DeploymentAvailability modes="self-hosted" />

From Mattermost v12.1, packaged releases include an offline documentation bundle, which is useful in [air-gapped environments](/deployment-guide/air-gapped-operations/index) or whenever the public documentation site isn't reachable. You can read it in two ways:

- **From the running server** at `/_documentation/`, for example `https://mattermost.example.com/_documentation/`.
- **From the command line** with [`mattermost docs`](/administration-guide/manage/command-line-tools#mattermost-docs), which serves the same bundle on localhost without requiring a running server, database, or configuration. This is useful for reading installation and troubleshooting documentation when the server is down.

<Note>

The `/_documentation/` route is not supported when `SiteURL` includes a subpath, such as `https://example.com/mattermost`. Use `mattermost docs` instead.

</Note>
